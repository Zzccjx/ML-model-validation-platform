# Scoring Methodology

## Platform Model Health Score
The platform generates an aggregate Model Health Score (0-100) representing the overall validation outcome.

## Formula
The score is a weighted average of individual category scores:
`Score = (W_perf * S_perf + W_data * S_data + W_fair * S_fair + ...) / Sum(W)`

In Phase 1, all weights are equal. Future versions will allow user-configurable weights.

## Category Scores
Each validator plugin generates a score from 0-100.
- **90-100**: Excellent
- **70-89**: Good
- **50-69**: Fair
- **<50**: Poor

## Disclaimers
The Model Health Score is an automated assessment based on statistical metrics. It is an indicator, not a definitive certification of safety, compliance, or business readiness.

## Severity Rules
Findings generated by validators are assigned severity levels based on configured thresholds:
- **CRITICAL**: Issues that severely compromise the model (e.g., Accuracy < 50%, severe bias).
- **HIGH**: Significant issues that should be addressed before deployment.
- **MEDIUM**: Noticeable degradations or moderate data issues.
- **LOW**: Minor issues.
- **INFO**: Informational observations.
